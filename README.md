# NexLab - Learn AI by Building

A modern, interactive learning platform for Indian students in classes 8-12 to learn AI, coding, and technology through hands-on project building.

## 🚀 Features

- **Learn by Building** - Project-based curriculum
- **Interactive Sandbox** - Write and run code in the browser
- **Gamification** - Earn XP, badges, and streaks
- **Student Showcase** - Share projects with the community
- **Indian Context** - Curriculum aligned with CBSE

## 🛠️ Tech Stack

### Frontend
- React 18 + TypeScript
- Vite - Build tool
- Tailwind CSS - Styling
- Zustand - State management
- React Router DOM - Navigation
- Framer Motion - Animations
- Monaco Editor - Code editing

### Backend
- Node.js + TypeScript
- Express.js - API framework
- MongoDB + Mongoose
- JWT Authentication
- Python Bridge - Code execution
